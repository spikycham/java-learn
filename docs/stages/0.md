# Stage 0

Date: 2026/11/04

## How to Guide the Author?

Make sure the author treats Java and Spring Boot like black box, he doesn't need to know the internals except when the internals affect the business logic too much.

In this stage, the main goal is to teach the author understand how to use Java and Spring Boot as a normal tool like blowing wind by a fan, calling through a phone. Don't introduce advanced features unless it has to be introduced.
